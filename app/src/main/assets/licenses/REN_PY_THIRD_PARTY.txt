Ren'Py 运行时第三方组件与许可证（内嵌于 GalgameShell）
====================================================

本 APK 内嵌 Ren'Py 安卓运行时（librenpython.so + assets/renpy-engine），
其许可证为 **MIT + 部分 GNU LGPL-2.1**。本文件列出静态链入 librenpython.so
的第三方组件及其许可证与对应源码地址，以满足 LGPL-2.1 §6 / AC-18 的
“提供对应源码”义务。

Ren'Py 主体
----------
- Ren'Py 引擎：MIT License
  源码：https://github.com/renpy/renpy

LGPL-2.1 组件（静态链入 librenpython.so）
----------------------------------------
- chardet       ：GNU LGPL-2.1
- FFmpeg        ：GNU LGPL-2.1
                  （实际许可取决于上游 RAPT 构建配置；本仓 vendored 预构建二进制，
                   对应源码见下方构建系统仓库）
- Fribidi       ：GNU LGPL-2.1
- libusb        ：GNU LGPL-2.1
- Pygame_SDL2   ：MIT License + GNU LGPL-2.1

其他宽松许可证组件
------------------
- Python（CPython 3.12）：Python Software Foundation License（宽松）
- SDL2                 ：zlib / BSD 风格（宽松）
- zlib / brotli / ANGLE 等：各自宽松许可证

对应源码获取（LGPL-2.1 §6 / AC-18）
----------------------------------
- Ren'Py 本体及依赖源码        ：https://github.com/renpy/renpy
- 构建系统（含上述 LGPL 组件源码、产生 librenpython.so 的构建脚本）
                              ：https://github.com/renpy/renpy-build
- pygame_sdl2 独立仓库         ：https://github.com/renpy/pygame_sdl2

LGPL-2.1 全文随本 APK 分发于 assets/licenses/LICENSE_LGPL-2.1.txt，
亦可在仓库根目录 LICENSE 查看。

GalgameShell 对 Ren'Py 运行时的修改仅限 Java 壳剥离 Google Play Asset
Delivery / IAP（不影响 LGPL 组件本身），完整对应源码公开于：
https://github.com/ReSerendipity/GalgameShell
